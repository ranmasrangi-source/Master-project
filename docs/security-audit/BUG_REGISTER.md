| **BUG-04** | **HIGH** | **P0** | Evidence Upload Size Mismatch & Streaming (`src/server/apiRouter.ts`, `src/server/evidenceProcessor.ts`) | `MAX_EVIDENCE_FILE_BYTES` allowed `10 MiB` binary files (~`13.33 MiB` Base64), but `express.json({ limit: '8mb' })` rejected valid `6–10 MiB` files before reaching the route; Base64 strings were decoded into memory before pre-checking character length; no binary stream upload path existed. | Mismatched Express JSON limit (`8mb` vs `15mb` required for `10 MiB` binary in Base64), missing pre-decode Base64 size/alphabet validator, and lack of `application/octet-stream` bounded stream reader. | **FIXED & VERIFIED** | `src/tests/bug01To10Remediation.test.ts` (`BUG-04`, 3 tests passing) |
